## 数值积分方法说明

### 1. 矩形法（左矩形）

**原理**: 将区间 `[a, b]` 等分为 `n` 个子区间，每个子区间取左端点函数值作为矩形高度。

**公式**:
```
I ≈ h × Σ f(xᵢ),  i = 0, 1, ..., n-1
```

**收敛阶**: O(h) = O(n⁻¹) —— 一阶收敛

### 2. 梯形法

**原理**: 用每个子区间两端点的平均值近似高度，面积为梯形面积之和。

**公式**:
```
I ≈ h/2 × [f(x₀) + 2×Σf(xᵢ) + f(xₙ)],  i = 1, ..., n-1
```

**收敛阶**: O(h²) = O(n⁻²) —— 二阶收敛

### 3. 辛普森法

**原理**: 每两个子区间使用二次函数（抛物线）近似被积函数。要求 `n` 为偶数。

**公式**:
```
I ≈ h/3 × [f(x₀) + 4×Σf(x₂ᵢ₋₁) + 2×Σf(x₂ᵢ) + f(xₙ)]
```

**收敛阶**: O(h⁴) = O(n⁻⁴) —— 四阶收敛

## 分析结论

1. **精度对比**: 在相同划分数量 `n` 下，辛普森法精度最高，梯形法次之，矩形法最低

2. **收敛速度**: 
   - 辛普森法（四阶）> 梯形法（二阶）> 矩形法（一阶）
   - 当 `n` 增加10倍时，辛普森法误差约减小 10⁴ = 10000 倍

3. **适用场景**:
   - **矩形法**: 实现最简单，适合快速估算
   - **梯形法**: 平衡了精度和复杂度
   - **辛普森法**: 对光滑函数效率最高，推荐用于高精度计算
