# 数值积分方法比较

本项目比较了三种数值积分方法（矩形法、梯形法、辛普森法）在计算定积分 \( I = \int_{0}^{\pi} \sin(x) \, dx \) 时的性能。

## 任务清单

- [x] 1. 导入所需库
- [x] 2. 定义被积函数 \( f(x) = \sin(x) \)
- [x] 3. 使用 SciPy 的 `quad` 函数计算高精度参考值
- [x] 4. 实现矩形法（左矩形）
- [x] 5. 实现梯形法
- [x] 6. 实现辛普森法（要求n为偶数）
- [x] 7. 定义n值列表（10, 20, 50, 100, 200, 500, 1000）
- [x] 8. 计算每种方法在不同n值下的近似值和相对误差
- [x] 9. 输出误差结果
- [x] 10. 绘制双对数坐标图（\( \log_{10}(n) \) vs \( \log_{10}(\text{error}) \)）
- [x] 11. 添加拟合直线并计算收敛阶

## 代码结构

- `f(x)`: 定义被积函数 \( \sin(x) \)
- `compute_reference_value()`: 使用 `scipy.integrate.quad` 计算高精度参考值
- `rectangle_method()`: 实现左矩形法数值积分
- `trapezoidal_method()`: 实现梯形法数值积分
- `simpson_method()`: 实现辛普森法数值积分
- `compute_errors()`: 计算不同方法在不同n值下的相对误差
- `print_errors()`: 输出误差结果
- `plot_errors()`: 绘制双对数坐标图并添加拟合直线
- `main()`: 主函数，执行所有计算和绘图
